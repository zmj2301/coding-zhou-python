# Alt+A 微信式截图工具

按下 **Alt+A** 键即可触发截图（微信未打开时）。全屏变暗、十字光标、自由框选、自动粘贴到微信。

## 功能

- **智能触发**：微信窗口可见时 Alt+A 无效；微信隐藏/关闭时正常触发
- **全屏变暗**：触发后屏幕覆盖半透明黑色遮罩
- **十字光标**：鼠标变为十字准星
- **框选区域**：按住左键拖拽出矩形选区
- **精确调整**：
  - 拖拽**边线/四角**调整选区大小
  - 拖拽**选区中间**移动位置
  - 右下角显示选区尺寸（宽 × 高）
- **完成截图**：
  - 双击选区内部
  - 或点击工具栏 **✓** 按钮
- **自动粘贴**：截图自动复制到剪贴板 + 自动粘贴到微信聊天输入框
- **取消**：按 **ESC** 或点击 **✕** 按钮
- **保存文件**：点击 **💾** 按钮选择保存位置

## 使用流程

```
1. 按 Alt+A  → 屏幕变暗 + 十字光标
2. 拖拽鼠标 → 框选截图区域（可选调整边缘/移动位置）
3. 双击选区 或 点击 ✓  → 截图完成
   ↓
   自动保存到 screenshots/ 目录
   ↓
   自动复制到剪贴板
   ↓
   自动粘贴到微信聊天输入框
   ↓
   用户点击微信「发送」
```

## 安装

```bash
cd 快捷键操作
pip install -r requirements.txt
python main.py
```

> **需要以管理员身份运行**，否则全局热键可能注册失败。

## 文件结构

```
快捷键操作/
├── main.py                  # 入口：热键注册 + 总控
├── screenshot_overlay.py    # 截图叠加层：变暗 + 框选 + 工具栏
├── wechat_detector.py       # 微信可见窗口检测
├── wechat_paster.py         # 自动粘贴到微信聊天输入框
├── requirements.txt         # 依赖
├── screenshots/             # 截图自动保存目录
└── README.md
```

## 依赖

| 库 | 用途 |
|----|------|
| pyautogui | 全屏截图 |
| Pillow | 图片裁剪、格式转换 |
| pywin32 | 剪贴板操作、窗口控制 |

## 快捷键

| 按键 | 功能 |
|------|------|
| Alt+A | 触发截图（微信未打开时） |
| ESC | 取消截图 |
| 双击选区 | 确认截图 |
| ✓ 按钮 | 确认截图 |
| ✕ 按钮 | 取消 |
| 💾 按钮 | 另存为文件 |
