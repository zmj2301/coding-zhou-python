3def greet(name):
4"""向指定的人打招呼。"""
5return f"Hello, {name}!"
6
7if __name__ == "__main__":
8print(greet("World"))
9# 控制台会输出: Hello, World!

📖 教学注释

第 3 行
定义函数 greet，参数 name 表示要问候的人的名字。
第 5 行
f-string 格式化字符串，{name} 会被替换为实际传入的值。这是 Python 3.6+ 推荐的字符串格式化方式。
第 7 行
if __name__ == "__main__" 是 Python 的惯用法，表示"当这个文件被直接运行时"才执行下面的代码。
