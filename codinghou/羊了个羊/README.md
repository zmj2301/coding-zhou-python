# 羊了个羊（codinghou 子项目）

基于 Pygame 的「羊了个羊」消除小游戏。多层堆叠的卡牌，玩家点击翻开并匹配相同的卡牌放入槽位，全部消除即通关；卡牌数据与布局参考 Scratch「羊了个羊」教程素材。

## 功能特性

- **经典消除玩法**：点击卡牌翻开，将相同的卡牌消入槽位
- **多层卡牌堆叠**：多图层叠放，上层卡牌覆盖下层，需按顺序消除
- **多种卡牌**：白菜、草叉、篝火、胡萝卜、剪刀、铃铛、麦捆、毛刷等 16 种
- **音效背景音乐**：播放游戏背景音乐，增强氛围
- **刮开/灰化处理**：支持卡牌灰色化与覆盖检测，正确判断可点击卡牌

## 环境要求

- Python 3.8+
- Pygame

```bash
pip install pygame
```

## 安装与运行

```bash
cd "codinghou/羊了个羊"
python main.py
```

## 核心实现

- 卡牌数据从 `Scratch羊了个羊教程-原始文件/` 中的坐标文件读取（如「第一层卡片x坐标.txt」「第一层卡片y坐标.txt」「第一层卡片编号.txt」）
- `is_cover(card_index)`：判断卡牌是否被上层卡牌覆盖
- `convert_to_gray()`：将已消除/覆盖的卡牌置灰
- 槽位匹配逻辑：点击两张相同卡牌自动消除

## 操作指南

1. 运行 `main.py` 启动游戏
2. 点击未被覆盖的卡牌，将其翻开并移入底部槽位
3. 匹配相同卡牌进行消除，全部消除即通关
