# 点亮家乡（湘潭手绘地图）

基于 Pygame 的「湘潭手绘地图」漫游查看器。加载湘潭手绘地图图片，支持缩放、平移漫游，并配有地标建筑导航功能，可用于浏览家乡地图、展示地标建筑。

## 功能特性

- **手绘地图展示**：加载「湘潭手绘地图.png」并自适应缩放显示
- **缩放漫游**：鼠标或键盘缩放地图（缩放步长 0.1），支持平移浏览
- **建筑导航**：`draw_navigation()` 函数实现地标建筑名称与图片切换导航
- **自适应布局**：根据目标窗口尺寸（800x600）自动计算初始缩放比例

## 环境要求

- Python 3.8+
- Pygame

```bash
pip install pygame
```

## 安装与运行

```bash
cd "codinghou/点亮家乡"
python show.py
```

## 项目结构

```
点亮家乡/
├── show.py            # 主程序：地图浏览与导航
├── text.py            # 辅助脚本
├── 点亮图片.py         # 图片相关辅助脚本
├── 湘潭手绘地图.png    # 地图图片（需放置于同目录）
└── README.md
```

## 核心实现

- `scale_image(rect, scale, x_offset, y_offset)`：按缩放因子与偏移计算图片位置
- `draw_navigation(...)`：绘制建筑名称与导航信息
- `MIN_SCALE` / `SCALE_STEP`：缩放范围与步长控制

## 使用说明

1. 将「湘潭手绘地图.png」放置于项目目录
2. 运行 `show.py` 打开地图
3. 通过滚轮/按键缩放、拖动平移浏览，使用导航查看地标建筑
