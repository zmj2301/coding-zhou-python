# codinghou

`codinghou` 是包含多个独立 Python 小项目的合集目录，每个子项目均可单独运行，涵盖小游戏、学习工具与算法练习。

## 子项目列表

| 子项目 | 类型 | 简介 |
|--------|------|------|
| [点亮家乡](点亮家乡/) | 小工具 | 湘潭手绘地图浏览与导航 |
| [我的世界](我的世界/) | 游戏 | Ursina 3D 我的世界仿制 |
| [学习资料](学习资料/) | 工具 | reportlab 生成数学题目 PDF |
| [羊了个羊](羊了个羊/) | 游戏 | Pygame 羊了个羊消除游戏 |
| [AI扑克牌](AI扑克牌/) | 游戏 | Pygame 扑克牌 AI 对战 |
| [python 五子棋](python 五子棋/) | 游戏 | Pygame + Ollama AI 五子棋 |

## 运行方式

每个子项目均为独立目录，进入子目录按各自 README 说明运行：

```bash
cd "codinghou/<子项目名>"
python <主程序>.py
```
