# Python 单词纠错

一个基于编辑距离（Edit Distance）算法的英文拼写纠错工具。程序扫描文本文件中的单词，与本地大型英语词典比对，找出拼写错误的单词并推荐最可能的正确写法。

## 功能特性

- **词库构建**：从单词列表文件构建大规模英语词典（集合结构，查询高效）
- **拼写检测**：扫描文本文件，定位每个拼写错误的单词及其行列位置
- **纠错推荐**：基于编辑距离算法，从词典中找出与错误单词最相似的单词作为建议
- **中文注释**：代码全程中文注释，适合学习算法与数据结构

## 环境要求

- Python 3.10+（使用了 `TypeAlias` 类型别名语法）
- 无需第三方依赖

## 安装与运行

```bash
cd "Python 单词纠错"
python main.py
```

程序会读取 `words_alpha.txt` 构建词典，扫描 `text.txt` 中的单词并输出纠错建议。

## 核心算法

### 编辑距离（Levenshtein Distance）

使用动态规划计算两个字符串间的编辑距离，即从 `s1` 变为 `s2` 所需的最少操作次数（插入、删除、替换各计 1 次）：

- `dp[i][j]` 表示 `s1` 前 i 个字符与 `s2` 前 j 个字符的编辑距离
- 当 `s1[i-1] == s2[j-1]` 时：`dp[i][j] = dp[i-1][j-1]`
- 否则：`dp[i][j] = 1 + min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1])`

### 主要函数

| 函数 | 作用 |
|------|------|
| `build_lexicon(filename)` | 从词典文件构建单词集合 |
| `edit_distance(s1, s2)` | 计算两字符串的编辑距离 |
| `most_similar_word(s, lexicon)` | 找出最相似的单词（编辑距离最小） |
| `scan_words(filename)` | 扫描文本，返回每个单词的行列位置 |
