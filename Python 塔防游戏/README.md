# Python 塔防游戏

基于 Pygame 的 2D 塔防游戏，敌人沿草地路径进攻，玩家通过放置防御塔阻止敌人到达终点。本实现通过图像颜色分析自动识别地图路径，实现了自动寻路与塔防攻防玩法。

## 功能特性

- **路径识别**：通过像素颜色分析（棕色路径 / 绿色草地）自动识别地图中的可行走路径
- **敌人系统**：敌人沿识别出的路径移动，支持多种敌人类型与属性配置
- **寻路算法**：基于颜色检测的自主寻路，含中心点、左右点、前方点三点检测
- **塔防玩法**：放置防御塔阻止敌人进攻，包含关卡系统与简单的经济系统
- **调试支持**：可在敌人身上绘制检测点，便于调试寻路逻辑

## 环境要求

- Python 3.8+
- Pygame

```bash
cd "Python 塔防游戏"

```

## 核心模块

### 敌人寻路系统（tafang.py）

| 元素 | 说明 |
|------|------|
| `Enemy` 类 | 管理敌人位置、速度、方向与移动 |
| `is_brown_pixel()` | 识别路径像素（棕色阈值判断） |
| `is_green_pixel()` | 识别草地像素（绿色阈值判断） |
| 三点检测 | 中心点（红）、左右点（绿）、前方点（蓝）协同判断行走方向 |

### 寻路策略

1. 读取地图背景图片像素颜色
2. 通过棕色 / 绿色阈值判断当前位置是否在路径上
3. 结合中心、左右、前方三个检测点，确定沿路径的移动方向
4. 敌人以 2 像素/帧的速度沿路径前进
