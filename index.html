关于 Code Explorer

Code Explorer 是一个在线 Python 项目浏览与运行平台。在这里你可以浏览、编辑并运行各种 Python 项目，包括游戏、AI 应用、实用工具等。部分网页游戏无需安装即可直接在浏览器中体验。

支持代码高亮、文件搜索、在线执行、留言交流等功能，让学习和分享代码变得更加便捷。
