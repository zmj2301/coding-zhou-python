## 数据获取核心逻辑

### 采集流程
1. **CollectorEngine** 根据用户选择的平台初始化对应 Scraper
2. 各 Scraper 并行（模拟）执行 `search(keyword)` 方法
3. 返回 List[Product] 统一数据模型

### 数据清洗与分析
- **去重**: 基于平台+名称前缀+价格近似值的组合键去重
- **排序**: 按价格从低到高排列
- **统计**: 价格区间（min/max/avg/median）、各平台概况
- **推荐算法**: `score = 40%价格优势 + 30%销量热度 + 20%店铺评分 + 10%折扣力度`

### 数据可视化方案
- **价格分布柱状图**: Chart.js bar chart，10个价格区间
- **平台对比图**: Chart.js 分组柱状图，展示各平台均价与最低价
- **商品对比表格**: 价格、折扣标签、评分进度条、平台徽章
- **TOP5推荐卡片**: 综合评分 + 四维度评分明细

## 快速使用

### 命令行

```bash
# 基础搜索（三平台全采）
python cli.py 手机

# 指定平台
python cli.py 笔记本 -p 京东 淘宝

# 输出JSON（供程序调用）
python cli.py 耳机 --json

# 保存结果到文件
python cli.py 手机 -o result.json

# 限制显示条数
python cli.py 手机 -n 20
```

### 演示网页
直接用浏览器打开 `web_demo.html`，页面加载后自动展示"手机"关键词的示例数据。

输入关键词点击"开始采集"即可生成新的模拟采集结果，包含完整的图表和推荐分析。

## 注意事项

- 当前版本使用模拟数据演示架构设计，真实采集需自行实现各平台的数据获取逻辑
- 真实采集需考虑反爬策略、请求频率控制、Cookie管理等
- 建议遵守各平台的 robots.txt 和用户协议
