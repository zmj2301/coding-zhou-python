# web-games / 我的世界（2D 方块建造）

网页版 2D 方块建造小游戏，模拟「我的世界」玩法。自动生成方块地形，玩家可放置与挖掘方块，使用数字键 1-7 切换不同材料，操作简单易上手。

## 功能特性

- **程序化地形**：`generateTerrain()` 自动生成起伏的方块地形
- **放置与挖掘**：左键放置方块、右键挖掘方块
- **材料切换**：数字键 1-7 切换不同材料（泥土、草地、石头等）
- **工具栏统计**：`countBlocks()` 统计各类方块数量并在工具栏显示
- **Canvas 渲染**：800x500 画布，点击格子交互

## 运行方式

纯前端项目，直接打开 `index.html`：

```bash
cd web-games
python -m http.server 8000
```

访问 `http://localhost:8000/my-world/`。

## 项目结构

```
my-world/
├── index.html      # 游戏页面
```

## 核心实现（index.html）

- `generateTerrain()`：随机生成地形高度并填充方块
- `place(x, y)` / `dig(x, y)`：放置 / 挖掘方块
- `updateToolbar()`：同步工具栏方块数量统计

## 操作指南

| 操作 | 功能 |
|------|------|
| 左键点击 | 放置方块 |
| 右键点击 | 挖掘方块 |
| 数字键 1-7 | 切换材料 |
