# web-games / 中国象棋

基于 Canvas 的网页中国象棋对战游戏。支持双人对弈与人机对战，人机模式玩家执红、AI 执黑。内置完整棋子走法校验、将军/胜负判定与 AI 走子逻辑。

## 功能特性

- **完整规则**：车、马、炮、相/象、仕/士、帅/将、兵/卒七种棋子，走法与吃子校验齐全
- **人机对战**：AI 执黑自动走子，玩家执红；可随时切换回双人对弈
- **悔棋**：支持撤销上一步
- **胜负判定**：将军与绝杀判定，游戏结束弹窗提示，可一键重开
- **分值评估**：内置棋子价值表（帅 10000、车 900、炮 450、马 400 等）用于 AI 决策

## 运行方式

纯前端项目，无需构建。直接打开 `index.html` 或在本地服务器中访问：

```bash
cd web-games
python -m http.server 8000
```

访问 `http://localhost:8000/chinese-chess/`。

## 核心实现（index.html）

- **棋盘模型**：9 列 x 10 行，红方在下方（y=7-9），黑方在上方（y=0-2）
- **棋子编码**：K=帅/将、A=仕/士、E=相/象、H=马/馬、R=车/車、C=炮/砲、P=兵/卒
- **类设计**：`ChineseChess` 类管理棋盘、走子、历史、AI 与渲染
- **AI 走子**：`aiTurn` 控制，基于合法走法枚举与分值评估选择落子

## 操作指南

| 按钮 | 功能 |
|------|------|
| 重新开始 | 重置棋盘 |
| 悔棋 | 撤销上一步 |
| 人机对战(红) / 双人对弈 | 切换模式 |
| 返回 | 回到游戏中心 |
