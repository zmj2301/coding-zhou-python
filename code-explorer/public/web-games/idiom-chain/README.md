# web-games / 成语接龙

基于网页的成语接龙游戏。玩家输入成语与 AI 对战，下一个成语首字需与上一个成语末字相同（支持同音字），AI 会自动在词库中寻找成语回应，内置词库与同音字表。

## 功能特性

- **成语接龙**：玩家与 AI 轮流接龙，遵守「首字 = 上句末字（可同音）」规则
- **内置词库**：内置数百个四字成语，自动清洗去重并建立「首字 → 成语列表」索引
- **同音字支持**：内置 `HOMOPHONES` 同音字表，末字与首字同音也可接龙
- **AI 回应**：`findIdiomStarting()` 自动查找符合规则且未用过的成语
- **界面动画**：用户/ AI 成语以不同颜色卡片展示，带淡入动画

## 运行方式

纯前端项目，直接打开 `index.html`：

```bash
cd web-games
python -m http.server 8000
```

访问 `http://localhost:8000/idiom-chain/`。

## 项目结构

```
idiom-chain/
├── index.html      # 游戏页面（含词库与逻辑）
└── README.md
```

## 核心实现（index.html）

- **词库清洗**：过滤非四字成语、去重，构建 `UNIQUE_IDIOMS`
- **索引构建**：`BY_FIRST` 以首字为键建立成语查找索引
- **接龙判定**：`isMatch(prevLast, nextFirst)` 判断末字与首字是否相同或同音
- **AI 选词**：`findIdiomStarting(ch, used)` 返回可接且未使用的成语

## 操作指南

1. 输入框中输入以指定字开头的成语
2. AI 自动接龙回应
3. 谁无法接出成语即失败
