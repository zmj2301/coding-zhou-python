🚀 使用说明

要使用本地运行功能，你需要在自己的电脑上运行 local_agent.py 伴生程序。

步骤 1： 下载 local_agent.py 文件到本地电脑。

步骤 2： 打开终端（CMD 或 PowerShell），运行：

python local_agent.py --projects-dir D:\你的项目目录

步骤 3： 运行成功后，此页面会自动检测到本地伴生程序，你就能看到项目列表并点击运行。

💡 提示：伴生程序仅在本地监听，不会对外暴露任何数据。

⚙️ 伴生程序端口

如果你的本地伴生程序使用的不是默认端口 18765，请在此输入实际端口号。
