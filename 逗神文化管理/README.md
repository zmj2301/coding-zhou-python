# 逗神文化管理

「逗神文化 / 逗神归来」视频学习平台的 Web 前端页面集合，包含项目首页、主页与 GitHub 风格展示页等多个静态页面，通过本地 HTTP 服务器即可浏览。

## 功能特性

- **项目首页**：`index.html`，展示「逗神文化」项目形象，采用渐变背景与响应式布局
- **平台主页**：`index-home.html`，视频学习平台主界面
- **GitHub 风格页**：`github-style.html`，类 GitHub 的项目/仓库展示页面
- **一键启动**：提供 `启动服务器.bat` 批处理脚本，双击即可启动本地服务

## 环境要求

- Python 3.x（用于启动静态服务器）
- 现代浏览器

## 安装与运行

### 方式一：双击批处理（推荐）

双击 `启动服务器.bat`，脚本会自动执行：

```
python -m http.server 8000
```

### 方式二：命令行

```bash
cd 逗神文化管理
python -m http.server 8000
```

启动后访问：

```
http://localhost:8000
```

## 项目结构

```
逗神文化管理/
├── index.html              # 项目首页（登录/引导页）
├── index-home.html         # 平台主界面
├── github-style.html       # GitHub 风格展示页
├── 启动服务器.bat          # 一键启动脚本（端口 8000）
└── README.md
```

## 使用说明

1. 双击 `启动服务器.bat`，终端输出「逗神归来 - 视频学习平台」提示
2. 浏览器访问 `http://localhost:8000`，即可查看各页面
3. 按 `Ctrl+C` 停止服务器
