## 交付：待办中心（单文件本地待办工具）

**需求**：把参考的 Linear 风格「项目管理工具」单页应用，最小幅度改造成**个人任务待办工具**，并支持导入用户本地的 Excel。

**产物**
- `output/待办中心.html` — 373KB 单文件成品，零外部网络请求（SheetJS 内联）
- `_src/todo-app.template.html` — 源码模板（占位符 `/*__SHEETJS__*/`）
- `_src/build.py` — 注入构建 + 6 项自检；改代码请改模板后重跑
- `_src/e2e.js` — Playwright 端到端测试，**131 项断言全通过**
- `_src/shots/` — 各断点截图

**关键决策**
- 参考文件 480KB 里有 407KB 是内联的 Tailwind 运行时，但 body 里 Tailwind 工具类使用数为 **0**（107 个类全是语义类）→ 直接砍掉，视觉零影响。Linear 观感来自那份 20KB 自定义 CSS 变量体系。
- SheetJS 选 **mini 版（273KB）** 而非 full（951KB）：mini 的 read/write/utils 齐全，读 xlsx 并自动修正浮点误差。
- 砍掉团队页（三页：仪表盘/待办看板/设置）；卡片去掉负责人字段；数据存 localStorage。
- 放弃了参考实现里的中英 i18n 层，硬编码中文（参考的中文串本身是占位级质量）。

**Excel 数据格式（用户本地文件的真实结构）**
两列：`time`（月.日 **数字**）+ `things`（事项文本）。`测试待办数据.xlsx` 13 条，跨度 09-15 ~ 12-31；`456.xlsx` / `text.xlsx` 是重复的测试数据；`7777777.xlsx` / `work.xlsx` 为空表。

**已确认的数据歧义**：`9.2` 与 `9.20` 在 Excel 中是同一个值，无法区分 9月2日 / 9月20日（用户数据里 `9.2`、`9.3` 两条恰好踩中）。未做猜测——导入对话框提供可切换规则（字面 / 补零）+ 实时预览。

**修掉的问题**
1. 变更后只重渲染当前页 → 活动日志在前端 DOM 里陈旧，违反「即时联动」要求。改为全量重渲染。
2. 导出时 `Number(a) + '.' + Number(b)` 被 JS 当字符串拼接，`time` 列写成文本型数字。已修正并加往返测试。
3. 暗色 `--text-tertiary: #52525b` 对 `#09090b` 仅 **2.40:1**（WCAG AA 需 4.5）→ 改 `#8b8b93` 达 **5.89:1**；亮色 `#a1a1aa` → `#8f8f96`（3.21:1，保留 Linear 式低对比元信息）。

**用户偏好（本任务新增）**：确认喜欢「导入对话框里给可切换规则而不是替他猜」的处理方式；在意离线可用（要求库内联而非 CDN）。

**技能沉淀**：`~/.workbuddy/skills/single-file-webapp-e2e`（单文件离线应用 + Playwright 端到端验收）。

## 三期：保存回 Excel + 长标题悬浮全文（同日完成）

**需求**（经确认选「导出回 Excel」）：① 调整后可保存——导出成与源文件完全同构的 xlsx，可覆盖原文件；② 长句被省略号截断时 hover 显示完整。

**改动**
- `saveToExcel()`：导出 `time`/`things` 两列、数字型月.日（9.2 不是 9.02，还顺手把源里的浮点脏值 9.199999999999999 还原成干净的 9.2）；文件名 = 最近导入的源文件名（`ui.sourceName`，build 时注入种子来源），下载即同名、拖回原目录即可覆盖。
- 「未导出」标记：任何任务变动 `markDirty()` → 日历页导出按钮出现琥珀色圆点 + 「有改动未导出」提示条；导出后 `markExported()` 消失，刷新后状态保留。主题/切页等 UI 状态不算 dirty。
- 设置页新增主按钮「保存为 Excel」，原四列导出改名「导出 Excel（含状态）」。
- 悬浮全文：chip/卡片标题挂 `data-full`（+`data-tip-sub` 元信息、`data-tip-desc` 描述），全局委托 `mouseover`，**只在真的被截断时**（scrollWidth/Height > client 检测）延迟 240ms 弹反色 tooltip；日历 chip 因几乎必截断带 `data-tip-always`。`refreshAll()` 里 `hideTip()` 防陈旧。
- 新增 `_src/verify_export.py`：独立于浏览器的 xlsx 结构校验（表头/行数/单元格类型/按标题配对日期/升序），E2E 下载的两份导出全部通过。

**验收**：calendar-e2e 91/91、e2e.js 132/132（修了 4 条二期前遗留断言：仪表盘→日历、种子动态为空、done 卡 ≥1）、导出结构校验 15 项全过；截图 `14-tooltip.png`。产物 397.7KB。
