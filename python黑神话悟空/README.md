# python黑神话悟空

基于 Pygame 的「黑神话悟空」像素风横版动作游戏。玩家操控孙悟空在多层卷轴背景中闯关，对抗妖魔鬼怪，包含敌人 AI、攻击动画、逐字字幕对话等系统，素材参考自 Scratch「黑神话悟空像素版」。

## 功能特性

- **横版动作玩法**：左右横版卷轴闯关，对抗敌人
- **多层视差背景**：远景、中景、地面三层卷轴背景，营造纵深感
- **敌人系统**：支持多个敌人同时在场，含接近/警戒状态机与生成逻辑
- **逐字字幕**：对话文字按速逐字显示，支持多行换行
- **角色动画**：玩家与敌人的攻击、行走动画
- **自定义字体**：使用项目内置字体文件渲染中文

## 环境要求

- Python 3.8+
- Pygame

```bash
pip install pygame
```

```bash
cd "python黑神话悟空"

```

## 核心类设计

| 类 | 作用 |
|----|------|
| `word_word_input` | 逐字字幕：按每秒 3 字符速度逐字显示，支持多行 |
| `Enemy` | 敌人管理：位置、状态机（接近/警戒）、生成与攻击逻辑 |

### 敌人状态机

- `standby_interval_dictionary_enemy`：不同状态（接近/警戒）的间隔帧数
- 敌人按帧更新，从屏幕右侧生成并向玩家逼近
- 支持记录玩家距离、多个敌人的独立管理

### 卷轴背景

三层背景图（远景/中景/地面）无缝拼接平铺，随玩家移动滚动，实现视差效果。

## 使用说明

1. 运行 `main.py` 启动游戏
2. 操控孙悟空击败关卡中的敌人
3. 与 NPC 对话时，字幕逐字显示剧情内容
