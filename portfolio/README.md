# portfolio 项目展示网站

CodingZhou 的个人作品集网站。采用 GitHub 风格界面，展示开发者的网页游戏、AI 项目与各类应用，支持项目搜索、分类筛选与项目详情预览。

## 功能特性

- **GitHub 风格界面**：侧边栏个人资料卡（头像、简介、项目/游戏/应用统计）、顶部导航
- **项目展示**：以卡片网格展示项目，含项目预览与简介
- **项目搜索**：顶部搜索框实时过滤项目（`filterProjects()`）
- **分类筛选**：项目 / AI 项目等分类视图
- **项目详情**：点击项目弹出详情面板，展示项目文件路径等信息
- **关于页面**：开发者自我介绍页面

## 运行方式

纯前端项目，直接双击打开 `index.html`，或启动本地服务器：

```bash
cd portfolio
python -m http.server 8000
```

访问 `http://localhost:8000/`。

## 项目结构

```
portfolio/
├── index.html      # 作品集网站
└── README.md
```

## 使用说明

1. 打开 `index.html` 进入作品集首页
2. 通过搜索框或分类标签筛选项目
3. 点击项目卡片查看项目详情
