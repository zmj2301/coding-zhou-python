# 消除动画：方块变成食物飞向宠物栏

## 需求概述

在每次消除方块后，增加动画效果：消除的动物方块会变成食物粒子，然后飞向右下角的宠物面板。

## 当前状态分析

### 消除动画实现（L1100-1107）

```javascript
async function animateClear(matches) {
  for (const [r,c] of matches) {
    const el=cells[r][c];
    if(el){ el.classList.add('clearing'); setScale(el,0); cells[r][c]=null; board[r][c]=-1; }
  }
  await sleep(260);
  boardEl.querySelectorAll('.clearing').forEach(el=>{ cellState.delete(el); el.remove(); });
}
```

* 问题：方块被缩放到0后立即从 DOM 移除

* 缺失：没有将方块转换为食物粒子的逻辑

### 宠物面板位置（L515-530）

* 初始在右下角(支持数百哦拖动移动位置，即位置不固定)：`position: fixed; bottom: 20px; right: 20px;`

* z-index: 50，在棋盘之上

* 食物显示：`<span id="foodCount">` 在 `.pet-food` 中

### 消除处理流程

* `trySwap()` → `processChainMatches()` → `animateClear()` → `animateDropAndFill()`

## 实现方案

### 1. 修改 `animateClear()` 函数

**目标：** 不立即移除元素，而是创建食物粒子

**修改内容：**

```javascript
async function animateClear(matches) {
  const foodParticles = [];

  for (const [r,c] of matches) {
    const el=cells[r][c];
    if(el){
      // 1. 缩放到0（消失效果）
      el.classList.add('clearing');
      setScale(el,0);
      cells[r][c]=null;
      board[r][c]=-1;

      // 2. 创建食物粒子（替换原元素）
      const particle = createFoodParticle(el, r, c);
      foodParticles.push(particle);
    }
  }

  await sleep(260);

  // 3. 移除原始元素
  boardEl.querySelectorAll('.clearing').forEach(el=>{ cellState.delete(el); el.remove(); });

  // 4. 触发食物飞向宠物面板
  await animateFoodToPet(foodParticles);
}
```

### 2. 添加 `createFoodParticle()` 函数

**位置：** 在 `animateClear()` 后添加

**功能：** 将 DOM 元素转换为食物粒子

```javascript
function createFoodParticle(sourceEl, r, c) {
  // 获取消除位置的中心坐标
  const rect = sourceEl.getBoundingClientRect();
  const boardRect = boardEl.getBoundingClientRect();

  // 创建食物粒子元素
  const particle = document.createElement('div');
  particle.className = 'food-particle';
  particle.innerHTML = '🍖';
  particle.style.fontSize = `${rect.width}px`;
  particle.style.position = 'fixed';
  particle.style.left = `${rect.left + rect.width/2}px`;
  particle.style.top = `${rect.top + rect.height/2}px`;
  particle.style.zIndex = '100';
  particle.style.pointerEvents = 'none';

  document.body.appendChild(particle);

  return { element: particle, startLeft: rect.left + rect.width/2, startTop: rect.top + rect.height/2 };
}
```

### 3. 添加 `animateFoodToPet()` 函数

**位置：** 在 `createFoodParticle()` 后添加

**功能：** 让所有食物粒子飞向宠物面板

```javascript
async function animateFoodToPet(particles) {
  const petPanel = document.getElementById('petPanel');
  if (!petPanel) return;

  const petRect = petPanel.getBoundingClientRect();
  const targetX = petRect.left + petRect.width / 2;
  const targetY = petRect.top + petRect.height / 2;

  // 计算每个粒子的飞行时间（距离越远越慢）
  const maxDistance = Math.max(
    Math.abs(particles[0].startLeft - targetX),
    Math.abs(particles[0].startTop - targetY)
  );

  // 所有粒子同时飞行
  for (const p of particles) {
    const distance = Math.sqrt(
      Math.pow(p.startLeft - targetX, 2) + Math.pow(p.startTop - targetY, 2)
    );
    const duration = Math.min(Math.max(distance / 10, 400), 800); // 400ms - 800ms

    p.element.animate([
      { transform: 'translate(0, 0) scale(1)', opacity: 1 },
      { transform: `translate(${targetX - p.startLeft}px, ${targetY - p.startTop}px) scale(0.3)`, opacity: 0 }
    ], {
      duration: duration,
      easing: 'cubic-bezier(0.25, 0.46, 0.45, 0.94)'
    });

    // 等待动画完成
    await new Promise(resolve => {
      p.element.addEventListener('transitionend', resolve, { once: true });
    });

    // 动画完成后更新食物数量
    food++;
    updateUI();
  }

  // 清理所有粒子
  particles.forEach(p => p.element.remove());
}
```

### 5. 修改 `processChainMatches()` 函数

**目标：** 在每次消除后触发食物动画

**修改内容：**

```javascript
async function processChainMatches() {
  let m = findMatches();
  let cascade = 1;
  while (m.length > 0) {
    console.log(`[DEBUG] 第${cascade}轮消除：找到${m.length}个方块，食物+${Math.floor(m.length / 2)}`);

    // 计算食物增量
    const foodGain = Math.floor(m.length / 2);
    food += foodGain;
    console.log(`[DEBUG] 消除后食物：${food}`);

    // 更新 UI
    updateUI();

    // 消除动画（包含食物粒子生成和飞向宠物面板）
    await animateClear(m);

    // 下落填充
    await animateDropAndFill();

    cascade++;
    m = findMatches();
  }
  console.log(`[DEBUG] 连锁消除结束，最终食物：${food}`);
}
```

## 预期效果

* **视觉反馈：** 消除的方块变成 🍖 食物，飞向宠物面板

* **动画流畅：** 使用 CSS transition 和 cubic-bezier 缓动函数

* **性能优化：** 使用 `will-change` 提示浏览器优化

* **多粒子支持：** 同时处理多个粒子的飞行

* **距离感知：** 飞行时间根据距离动态计算

## 技术细节

### 动画性能优化

* 使用 `requestAnimationFrame` 优化（通过 CSS transition）

* 使用 `will-change: transform, opacity` 提示浏览器

* 粒子动画完成后立即从 DOM 移除

### 边界情况处理

* 如果宠物面板不可见（如商店打开），粒子直接消失

* 如果没有消除方块，不触发动画

* 使用 `try-catch` 防止异常中断

### 浏览器兼容性

* 使用标准 CSS transition

* 使用 `getBoundingClientRect()` 获取坐标

* 兼容所有现代浏览器
