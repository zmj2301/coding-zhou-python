# 口算战争

一款基于 Pygame 的口算练习 + 飞机大战二合一游戏。玩家通过完成口算题目击败敌人，用赚取的金币购买道具、皮肤与背景，在「口算战争」与「飞机大战」两种模式中切换游玩。

## 功能特性

- **口算模式**：实时出题作答，答对攻击敌人，答错受到威胁，锻炼心算能力
- **飞机大战模式**：经典竖屏射击玩法，控制飞机躲避岩石、发射子弹消灭敌人
- **经济系统**：通过答题和战斗积累金币，用于购买道具、皮肤与背景
- **道具系统**：如简单题目、护盾等道具，提升游戏体验
- **玩家数据持久化**：金币、已购背景、当前背景、已购道具等状态自动保存到本地 JSON
- **资源管理**：统一封装图片、音频、字体等资源加载，支持 SVG 生成图片素材

## 环境要求

- Python 3.8+
- Pygame

## 安装与运行

```bash
cd 口算战争
pip install pygame
python oral_calculation_practice.py
```

运行飞机大战模式：

```bash
python plane_war.py
```

> 飞机大战模式需要 `img_plane/` 目录下的图片资源。

## 核心模块

| 模块 | 职责 |
|------|------|
| `GameEngine` | 控制整个游戏生命周期与流程，统一管理状态、资源、UI 与逻辑 |
| `GameState` | 维护玩家状态、金币、道具与商店数据 |
| `ResourceManager` | 负责图片、音频、字体等资源的加载与缓存 |
| `shop_categories` | 商店商品分类定义 |

## 操作指南

- **口算模式**：阅读题目 → 输入答案 → 答对攻击敌人 / 答错受到威胁
- **飞机大战模式**：方向键或鼠标控制飞机移动，空格射击
- **商店**：在主界面进入商店，使用金币购买道具、皮肤与背景
- **数据存档**：玩家状态实时写入 `user_data.json`，重启不丢失

## 配置文件说明

- `user_data.json`：存储玩家金币数量、已购背景、当前背景、已购道具等
- `level.json`：存储关卡相关配置

## 打包说明

代码中预留了 `auto-py-to-exe` 打包注释，可用该工具将游戏打包为独立的 exe 文件。
