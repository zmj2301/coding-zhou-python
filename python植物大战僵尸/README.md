# python植物大战僵尸

基于 Pygame 的「植物大战僵尸」(Plants vs Zombies) 仿制游戏。玩家在 5 行草地上种植多种植物（豌豆射手、向日葵、樱桃炸弹、双发射手、投手、食人花、太极、火炬树桩、辣椒、玉米投手等），抵御一波波僵尸的进攻，保卫家园。

## 功能特性

- **经典塔防玩法**：种植植物抵御僵尸进攻，收集阳光购买植物
- **多种植物**：11 种植物，各有攻击方式、冷却时间、阳光消耗与特殊能力
- **多种僵尸**：普通僵尸、路障僵尸、铁桶僵尸等，血量各异
- **子弹系统**：豌豆、白菜、火豆、玉米等多种子弹类型，伤害不同
- **阳光经济**：向日葵产阳光，僵尸被消灭/植物被清除可回收阳光
- **铲子系统**：普通铲子移除植物，银铲子移除并回收 10% 阳光
- **动态加载**：植物、僵尸、子弹动画帧加载与管理
- **日志记录**：内置 `日志.py` 记录运行过程

## 环境要求

- Python 3.8+
- Pygame、numpy

```bash
pip install pygame numpy
```

## 安装与运行

```bash
cd "python植物大战僵尸"
python PVZ.py
```

## 核心系统

### 植物系统

- `plant_sun`：各植物阳光消耗（豌豆 100、向日葵 50、樱桃 150、太极 600 等）
- `plant_firing_`：各植物攻击/产阳光间隔
- `plant_bullet`：各植物对应子弹类型
- `plant_related_health_volume`：植物血量

### 僵尸系统

| 僵尸 | 血量 |
|------|------|
| 普通僵尸 | 240 |
| 路障僵尸 | 740 |
| 铁桶僵尸 | 1040 |
| 铁门僵尸 | 840 |

### 子弹系统

| 子弹 | 伤害 |
|------|------|
| 豌豆 | 20 |
| 白菜 | 40 |
| 火豆 | 50 |
| 玉米 | 20 |

## 操作指南

1. 运行 `PVZ.py` 启动游戏
2. 收集阳光，点击卡牌选择植物并种植到草坪格子
3. 合理安排植物搭配，抵御僵尸进攻
4. 使用铲子移除或调整植物布局
