# Python冰火两重天

基于 Pygame 的双色闯关小游戏（仿「冰火人」玩法）。玩家操控角色在红色与蓝色的障碍与平台间穿梭，躲避陷阱、收集目标，挑战关卡。项目同时附带一个 C++ 编写的十六进制转十进制算法程序。

## 功能特性

- **双色机关玩法**：红色与蓝色障碍物，需要根据角色属性选择可通行区域
- **完整游戏循环**：包含开始、运行、失败（game over）与重开状态管理
- **物理运动**：玩家移动、跳跃与障碍碰撞检测
- **关卡设计**：根据关卡贴图（level1.png 等）布置的红蓝障碍物
- **日志系统**：内置 logging 记录运行过程，便于调试

## 环境要求

- Python 3.8+
- Pygame

```bash
pip install pygame
```

## 安装与运行

```bash
cd "Python冰火两重天"
python main.py
```

```
Python冰火两重天/
```

## 核心类设计（main.py）

| 类 | 作用 |
|----|------|
| `Game` | 游戏主控：初始化窗口、管理游戏状态、障碍物与主循环 |
| `Player` | 玩家角色：移动、跳跃与状态控制 |

### 游戏状态

- `running`：游戏运行中
- `game_over`：失败状态，记录失败时间
- 窗口尺寸 800x600，标题「Python 冰火两重天」

## 使用说明

1. 运行 `main.py` 启动游戏
2. 控制角色躲避红蓝障碍物，通关目标关卡
3. 失败后自动进入 game over 状态，可重新开始

## 附：main.cpp

`main.cpp` 实现了十六进制字符串转十进制数值的算法，作为独立的学习示例编译运行。
