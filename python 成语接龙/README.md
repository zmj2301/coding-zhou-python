# python 成语接龙

基于 Tkinter 的成语接龙游戏，支持人机对战、成语查询、拼音与数字辅助等多种玩法，附带成语词库构建与数据处理脚本。

## 功能特性

- **成语接龙**：经典接龙玩法，玩家与电脑轮流接成语，接不上即失败
- **人机对战**：电脑自动从成语库中查找符合规则的成语进行回应
- **成语知识辅助**：内置成语列表、汉字列表、拼音列表与数字列表，辅助判断接龙规则
- **网络检测**：启动时自动检测网络连接，便于后续功能使用
- **GUI 界面**：基于 Tkinter 构建友好的图形界面

## 环境要求

- Python 3.7+（仅标准库，无需第三方依赖）

## 安装与运行

```bash
cd "python 成语接龙"
python 成语接龙03.py
```

## 项目结构

```
python 成语接龙/
├── 成语接龙01.py / 02.py / 03.py   # 游戏不同版本（03 为最终版）
├── 数据来源.py                      # 数据来源说明与处理脚本
├── 成语列表.txt                     # 成语词库
├── 汉字列表.txt                     # 常用汉字列表
├── 汉字拼音.txt                     # 汉字拼音对照
├── 数字列表.txt                     # 数字词库
├── data/                            # 数据文件目录（含 idiom.json 等）
├── my_idiom_book.txt                # 个人成语本
├── text.py / text copy.py           # 数据处理脚本
└── README.md
```

## 使用说明

1. 运行 `成语接龙03.py` 启动游戏
2. 程序会读取成语列表、汉字列表等词库文件，自动检测网络
3. 按照接龙规则输入成语，电脑自动接龙，比拼谁先词穷

### 数据来源

成语及汉字数据参考自开源项目 [chinese-xinhua](http://github.com/pwxcoo/chinese-xinhua) 的 `idiom.json` 数据，可通过 `数据来源.py` 处理生成词库文件。
