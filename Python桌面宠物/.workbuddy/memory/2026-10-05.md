### 关键发现
1. **WorkBuddy 没有「用量历史」接口**（客户端源码里 `usage()` 是返回空数组的桩），
   只能轮询余额做差值近似当日消耗 → 必须本地存档才能算趋势。
   MiniMax 同理。
2. 日型权重直接复用 TRAE 项目的 `school_calendar.py`（sys.path 注入 `/opt/trae-work`），
   保证两边节假日判断一致。已验证：国庆 10/1~10/7 = full，
   10/8~10/10 = off（10/10 是调休补班），周五 = half。
3. `school_calendar` **没有** `is_school_mode()` 函数，
   要读 `load_cfg().get("school_mode")` 才是开学模式。

### 预测算法（按用户三个需求）
1. **今日用量最大化**（不超过上限）：给区间不是单点。
   下限 = 到最近到期事件前必须烧掉的量（防浪费）；
   上限 = 积分包总量；目标 = `max(常规预测, 防浪费底线)` 再夹进上限；
   上学日目标直接 0
2. **剩余告警**（对标钉钉剩余提醒）：三档。
   可用天数 ≤5 或剩余 ≤10% → 黄(ok/warning/critical)；≤2 天 → 红
3. **耗尽预测 + 到期规划**：按加权日均逐日扣，**自动跳过上学日**（权重 0）；
   到期规划算出每个包「到期前必须用多少 ÷ 到期前可用日数」= 需日用量 + 风险等级

历史数据归一化：直接对历史求平均会把「上学日用得少」误当成「用得少」，
所以要除以当天日型权重，得到「一个可用日的平均消耗」再乘今天权重。

### 踩过的坑（重要）
1. **`http_proxy` 环境变量会劫持本地请求**：本机设了 `http_proxy=127.0.0.1:56491`，
   urllib 会把 `127.0.0.1:8899` 的请求也发给代理，返回 **502 Bad Gateway**，
   极易误判成「隧道没通 / ECS 服务挂了」。必须
   `urllib.request.build_opener(urllib.request.ProxyHandler({}))` 绕过。
2. **`SSH_TARGET` 必须是 `user@host` 形式**：写裸 IP 会用本机用户名登录，
   报 `Administrator@39.107.96.165: Permission denied (publickey)`。
3. **`tasklist` 输出在中文 Windows 是 GBK**，`text=True` 会抛
   UnicodeDecodeError 导致 `tunnel.py stop/status` 直接崩，
   要用 `capture_output=True` + `.decode("utf-8", errors="replace")`。
4. **跨天归一化**：用余额差值算消耗时，若跨天了要把这段消耗记到前一天，
   否则会把昨天的量算到今天头上（`last_seen_date` 字段）。
5. **沙箱/后台命令结束会清理子进程**：ssh 隧道活不过单次 bash 调用。
   这是环境限制，不是代码问题；真实桌面环境用 `DETACHED_PROCESS` 是有效的。
6. `fromisoformat` 是 Python 3.7+ 才有的，面板里改用 `strptime` 手工截取。
7. 路径含中文时 `scp` 会失败（`Failure`），需先 cp 到纯 ASCII 临时路径再传。
8. 远程后台启动要用 `setsid nohup ... &`，否则 ssh 断开时进程被一起杀掉。
