# 作业拍摄支架 · 零基础操作手册

> 你不需要懂电路。这份手册假设你只会用电脑和浏览器。

---

## 第一部分：这个东西到底是干什么的

想象这样一套设备：

```
     ┌─────────────────────────────┐
     │      桌边夹紧的金属支架       │
     │                             │
     │      ┌───────────┐          │
     │      │  摄像头    │← 镜头对着下面的纸│
     │      └───────────┘          │
     │        (灯环)               │  ← 环形补光灯套在镜头外面
     │                             │
     └───夹─────────────────────────┘
                    ↓
              作业纸平铺在桌面
                    ↓
              USB 线连到电脑
```

**它做的事**：你把作业纸铺在桌上，按一下键盘空格，屏幕上弹出的程序就把这一页拍下来、自动拉正、自动增强清晰度，存进电脑文件夹。

**你不需要做的事**：接线、焊接、看电路图、量电压。所有东西都是插头对插口。

## 第三部分：收到货后怎么装（10 分钟）

### 步骤 1 · 先试摄像头，别急着装支架

1. 摄像头 USB 线插到电脑（插机箱前面的口，蓝色/白色那个）
2. 摄像头那头插上
3. 打开「相机」应用（Windows 开始菜单搜"相机"）

**看到画面 = 摄像头没问题**，可以继续买支架。**黑屏或找不到 = 立刻申请退货**，别等支架到货。

### 步骤 2 · 夹紧支架

1. 把夹子**卡进桌沿**
2. 拧紧下面的旋钮，晃一下桌面看稳不稳
3. 注意夹在**桌子的厚实位置**，别夹薄桌沿（会慢慢滑下来）

> 桌面厚度一般 2～4cm 的都能夹。桌沿太薄的话，上面的夹子往往带可调节的滑槽。

### 步骤 3 · 装摄像头

1. 摄像头**底部**有个小孔（1/4 英寸螺孔），银色的
2. 支架**顶端**有根螺杆对准它
3. **拧的时候用手扶住摄像头**，拧紧即可

> 拧之前先把 USB 线从支架顶端的孔穿过去，这样线不会在摄像头转动时被拉扯。

### 步骤 4 · 装补光灯

1. 灯的夹子**夹在支架立柱上**，不用扶着手拿
2. 灯环**套在镜头前面**，是个圈，镜头在圈中间——不是挡在镜头前面
3. 灯的 USB 线沿支架走线，用**扎带或餐夹**固定在支架上，别让它垂下来碰到作业纸

### 步骤 5 · 调整位置

| 距离 | 效果 |
|---|---|
| 15 cm | 只能拍一小块字 |
| **20～30 cm** | ✅ **推荐**：A4 纸大致铺满画面 |
| 50 cm 以上 | 画面太小，小字看不清 |

**灯从正前方打**（镜头和灯在同一侧对着纸），避免从侧面打造成的阴影。

## 第四部分：跑拍照程序（一次性设置）

### 装依赖库（只做一次）

打开命令行窗口：
- 在文件夹地址栏输入 `cmd` 回车，或者
- 开始菜单搜"命令提示符"

粘贴这行进去，回车：

```bash
pip install opencv-python numpy
```

第一次会下载几十 MB，等它跑完看到 `Successfully installed` 就成了。

### 启动程序

**方法一（推荐）**：在 `作业拍摄支架` 文件夹里按住 Shift + 鼠标右键 → "在此处打开 PowerShell 窗口"，然后：

```bash
python 拍照助手.py
```

**方法二**：在任意位置打开命令行，输入完整路径：

```bash
cd "E:\coding-zhou\Python\摄像头测试\作业拍摄支架"
python 拍照助手.py
```

### 按键说明

| 键 | 作用 |
|---|---|
| `空格` / `回车` | 拍一张 |
| `B` | 批量连拍 15 张（拍整套作业用这个） |
| `T` | 5 秒后自动拍一张（等作业墨水干） |
| `Q` / `Esc` | 退出 |

### 照片存哪

`作业拍摄支架/photos/日期/`，比如 `photos/2026-10-17/作业_143052.jpg`

## 第五部分：万一出问题了

### 程序报"打不开摄像头"

按顺序排查：

1. **USB 线换个电脑口插** — 尤其是从机箱前面插到机箱后面试试
2. **检查 Windows 隐私设置** — 设置 → 隐私和安全性 → 相机 → "允许应用访问相机"打开
3. **摄像头被别的软件占用** — 关掉正在开摄像头的微信/QQ/钉钉/浏览器标签页
4. **换个摄像头编号** — 把脚本里 `CAMERA_INDEX = 0` 改成 `1`，`2` 试试

### 拍出来很模糊

| 原因 | 解决 |
|---|---|
| 纸离镜头太近（<15cm）| 拉远到 20～30cm |
| 摄像头没有自动对焦 | 这是硬件问题，拍下型号图申请退货 |
| 光线不足 | 补光灯开到最亮 |

### 自动裁切没生效

程序**不会报错**，只是保存原图。想提高成功率：

1. 让作业纸和桌面**颜色有差别**（白纸 + 深色桌面最好）
2. 纸**四角都露在画面里**，不要有一角被裁出画面
3. 光线均匀，不要一半亮一半暗

实在不行，把脚本里 `AUTO_CROP = True` 改成 `False`，直接关掉这个功能。

### 拍出来太暗 / 铅笔字看不清

这是正常情况，程序的增强功能应该已经处理了。如果还是不行：

- 确认**补光灯是开着的**
- 换用**黑色/深色笔**写作业的纸（白底深字对比度高）
- 如果用黑色桌面效果最好

## 第六部分：可以调的地方

脚本顶部有一堆设置，都改注释掉的那一行即可：

```python
SAVE_DIR = "photos"          # 照片存哪
ENHANCE = True               # 图像增强（铅笔字看不清就开着）
AUTO_CROP = True             # 自动裁切拉正
MAX_WIDTH = 3840             # 最大宽度，默认输出 4K 尺寸
CAMERA_INDEX = 0             # 摄像头编号
```

**如果觉得增强过头、图片发白**，把 `ENHANCE` 关掉试试：

```bash
python 拍照助手.py --no-enhance
```
