## 三步走

### 1️⃣ 买（约 179 元）

⚠️ **下单前先发消息问客服**，确认底部有 1/4 英寸螺孔 + 对焦距离能到 15cm。
话术在 `采购清单.html` 里，可直接复制。

### 2️⃣ 装（约 10 分钟）

桌面夹夹桌沿 → 摄像头装到支架顶部 → 台灯放在镜头**同侧前方** → 铺纸，调到 15～20cm 高度。

**不需要接线、不需要焊接。**

**关键技巧**：灯、镜头、作业纸三点在一条线上，光"顺着"镜头打，阴影会落在镜头死角里，画面均匀无斜影。

### 3️⃣ 用（一次性设置）

```bash
pip install opencv-python numpy
python 拍照助手.py
```

然后按 **空格** 拍照。

## 常见问题

**Q: 需要懂电路吗？**
不需要。所有部件都是即插即用标准件，唯一的技术活是运行一个 Python 命令。

**Q: 摄像头为什么不买便宜的？**
最初预算 100 元，但调研发现：4K 模组普遍 115 元起，且裸板无外壳无螺孔。最终找到 127 元的 2K 金属壳无畸变款，**且支持 7 天无理由退货 —— 试错零成本**。

**Q: 按钮要接线吗？**
不用。USB 快门按钮是内置固件的 USB 设备，电脑识别为"键盘"，按一下 = 空格字符。**插上即用，程序零改动**（已预留支持）。

**Q: 铅笔字拍出来不清楚？**
程序会自动提亮 + 增强对比度。另外建议用**深色桌面**摆白纸，对比度最大化。

**Q: 能卡死 100 元吗？**
可以：把摄像头换成同店的 `1080P 3.6MM 无畸变` 规格（便宜约 40～50 元），其余参数一致，程序完全兼容。
