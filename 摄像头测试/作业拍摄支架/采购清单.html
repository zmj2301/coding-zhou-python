📦 到货后验收（5 分钟，别跳过）

  1. 先不装支架摄像头直接插电脑，打开 Windows「相机」应用，看有没有画面
  2. 测近距离清晰度把镜头怼到 15～20cm 外的有字纸面，看小字是否清楚。这一步不过关，直接申请退货
  3. 测分辨率在「相机」设置里看能否切到 4096×2160。切不了也不影响，程序会自动用最高可用分辨率
  4. 装支架桌面夹夹桌沿 → 摄像头装到顶部 → 台灯放在镜头同侧前方 → 作业纸平铺，调到 15～20cm 高度
  5. 跑程序打开命令行 → cd "E:\coding-zhou\Python\摄像头测试\作业拍摄支架" → pip install opencv-python numpy → python 拍照助手.py → 按空格拍照
装支架的关键技巧 灯、镜头、作业纸三点在一条线上——灯在最靠前，镜头在中间，纸在最后。 这样光"顺着"镜头方向打，纸面的阴影会落在镜头自己的死角里，画面均匀、没有斜向硬阴影。 如果灯和镜头分列左右两边，纸面上会有一道明显斜影，铅笔字会变成灰色影子看不清。
