# 2026-10-17

## 作业拍摄支架项目（调研 + 方案落地）

**需求**：架起支架拍照、连电脑、拍纸质作业文件、硬件≤100元、手动/代码双触发、零基础用户。

**关键技术判断**：
- 查证后砍掉 4K：入门4K UVC模组115元起（IMX334 正规款328元），会超预算；且拍纸质文件的清晰度主要取决于光照均匀度+对焦距离，而非像素数。
- 选定OV5648 类 1080P **自动对焦** UVC 摄像头（对焦距离 10cm 起）——定焦镜头在 20cm 拍摄距离会拍虚，这是本场景的关键约束。
- 电脑体检：MAXSUN B760M D5 + Intel USB 3.20 控制器（ROOT_HUB30 存在），USB3.0 带宽充足，无需考虑降级。

**成本结构**：摄像头55 + 环形灯18+ 桌夹悬臂22 ≈ 95元。
支架必须选带 **1/4 英寸螺孔** 的，这是装摄像头和灯的通用接口。

**交付物**（目录 `作业拍摄支架/`）：
- `采购清单.html` —— 可直接照着买的清单，含搜索关键词与买错风险提示
- `操作手册.md` —— 零基础组装/上手/排障手册
- `拍照助手.py` —— 270 行拍照程序（OpenCV），功能：实时预览、空格拍照、批量连拍、定时拍摄、自动纸张轮廓检测+透视校正裁切、纸面增强（白平衡/CLAHE/锐化）、2倍超分放大
- `README.md`

**程序设计要点**：
- 自动裁切用 Canny + findContours + approxPolyDP 取四边形 + getPerspectiveTransform 拉正；检测失败**静默回退到原图不报错**（零基础用户不该看到崩溃）
- 修了批量模式的 `last_batch` 未初始化问题（`dir()` 局部变量检测不可靠）
- 保存路径按日期分目录

**下一步**：等用户采购到货后，实机联调摄像头实际分辨率/对焦表现，可能需要调整 CANNY阈值或 MIN_AREA_RATIO。

## 方案迭代（用户实际选品后修订）

**重要修订**：砍4K 的判断被推翻——用户自己在天猫找到了 127 元的 2K（4096×2160）金属壳无畸变工业摄像头（技彩科技）。最初按"4K 必超预算"的估计过于保守，实际比预估便宜。**教训：电商价格波动大，不宜基于搜索摘要断言价格区间，应给出决策树让用户自己核价。**

**最终配置（≈179 元）**：
| 物品 | 规格 | 价 |
|---|---|---|
| 技彩 USB工业摄像头 | 2K + 3.6MM 无畸变 + 金属外壳 | 127 |
| 悦瑞客悬臂支架 | （13mm铝方）68cm 升降杆 + 桌面夹 | 52 |
| 台灯 | 代替环形补光灯 | 0（用户家里有） |
| USB 快门按钮 | 决定不买 | — |

**关键选型判据 —— 焦距与拍摄距离的定量关系**（本项目最有价值的推论）：
- 3.6MM（约90°视场角）拍满A4 只需 **15cm** 距离 → 支架高度合适 ✅
- 2.8MM（约125°视场角）拍满 A4 需 **8cm** → 作业纸塞不进画面，且边缘拉伸变形 ❌
- 以后遇到"选镜头焦距"类问题，直接用 `距离 = (纸张宽度/2) / tan(FOV/2)` 估算。

**补光灯替代方案**：家用台灯可用，但必须 **灯/镜头/纸三点共线**（灯最靠前），光顺镜头方向打，阴影才落在镜头死角里。分列两侧会产生斜向硬影，铅笔字变成灰影。

**USB 快门按钮（用户反复追问）**：**无需接线**。本质是内置固件的 USB 假键盘，按一下发空格字符。程序已预留支持，插上即用零改动。

**沟通教训**：用户连续多轮表达"到底怎么办/能不能给个准话"，说明前期输出**风险提示过多、决策不够收敛**。修正方式：给出**单一明确推荐 + 定量判据 + 决策树**，而非罗列所有可能性与风险。
