# python父亲节祝福

父亲节爱心祝福网页，采用流动渐变背景、爱心粒子、祝福文字与交互动画，是一款视觉华丽、可直接打开的静态网页。项目另附 C++ 排序算法示例程序。

## 功能特性

- **流动渐变背景**：深色渐变背景以 `transform` 动画流动，性能优于 background-position 动画
- **爱心特效**：飘落的爱心粒子动画营造温馨氛围
- **祝福文案**：精美的父亲节祝福文字展示
- **交互动画**：页面元素含过渡与动画效果
- **响应式**：适配不同屏幕尺寸

## 环境要求

- 现代浏览器（无需安装任何依赖）

## 安装与运行

直接双击打开 `index.html`，或启动本地服务器：

```bash
cd "python父亲节祝福"
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 项目结构

```
python父亲节祝福/
├── index.html    # 父亲节祝福网页
├── app.cpp       # C++ 学生成绩排序示例
├── .trae/        # 开发辅助配置
└── README.md
```

## 使用说明

1. 打开 `index.html` 即可看到祝福页面
2. 页面的爱心与背景动画自动播放
3. 可自由修改 CSS 中的配色与祝福文案内容

## 附：app.cpp

`app.cpp` 是一个 C++ 程序：输入学生人数与成绩，按成绩降序输出排序结果，作为算法学习示例。
