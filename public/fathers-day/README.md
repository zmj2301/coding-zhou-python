# fathers-day 父亲节祝福

父亲节爱心祝福网页，采用流动渐变背景、漂浮祝福语卡片、爱心粒子动画与轮播祝福语等效果，是一款视觉华丽、可直接打开的静态网页。

## 功能特性

- **流动渐变背景**：深色渐变背景以 `transform` 动画流动，性能优于 background-position 动画
- **漂浮祝福卡片**：多张不同配色倾向的祝福语卡片无限循环漂浮
- **爱心粒子动画**：爱心特效元素点缀页面
- **祝福语轮播**：内置 137 条祝福语随机展示，支持逐条轮播
- **手机特效**：底部祝福语含手机端适配效果
- **响应式布局**：适配不同屏幕尺寸

## 运行方式

纯前端项目，直接双击打开 `index.html`，或启动本地服务器：

```bash
cd fathers-day
python -m http.server 8000
```

访问 `http://localhost:8000/`。

1. 打开 `index.html` 即可看到祝福页面
2. 漂浮卡片与爱心动画自动播放
3. 可自由修改页面中祝福语文案与配色
