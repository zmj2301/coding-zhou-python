# web-games / 口算战争

网页版「口算战争」游戏：通过完成口算题攻击敌人。题目难度分级（简单/中等/困难），答对攻击敌人并叠加连击加分，答错受到威胁。Canvas 实时渲染战斗画面。

## 功能特性

- **口算出题**：按难度生成加减乘除题目（`DIFFICULTY` 配置运算符号与数值范围）
- **战斗玩法**：答对攻击敌人，答错受威胁；消灭敌人获得分数
- **连击系统**：连续答对叠加连击，分数加成（`gain = 10 + combo * 2`）
- **难度选择**：支持切换简单/中等/困难三个等级
- **实时 UI**：题目、分数、敌人状态与战斗动画同步更新

## 运行方式

纯前端项目，直接打开 `index.html`：

```bash
cd web-games
python -m http.server 8000
```

访问 `http://localhost:8000/math-war/`。

## 项目结构

```
math-war/
├── index.html      # 游戏页面（Canvas 480 宽战斗画面）

```

## 核心实现（index.html）

- `genQuestion()`：按当前难度随机生成题目（运算类型、数值范围来自 `DIFFICULTY[level]`）
- `submitAnswer()`：校验答案，正确则攻击敌人并计分，错误则触发失败逻辑
- `nextQuestion()`：生成下一题并刷新题目显示
- 玩家固定在左侧，敌人从右侧逼近

## 操作指南

1. 选择难度等级
2. 阅读题目，在输入框填写答案并提交
3. 答对攻击敌人、答错受损，消灭全部敌人获胜
