# python 计算机

复刻「2026 马年 Fast Magic」的魔术计算器程序。基于 Tkinter 的图形计算器，通过读取当前系统时间生成「预计算数字」，实现点击任意数字后立即显示完整数字的魔术效果。

## 功能特性

- **基础计算器**：支持常规数字输入、四则运算与等号计算
- **魔术模式**：按下等号后，点击任意数字即可立即显示基于当前时间的完整预计算数字
- **时间感知**：自动读取系统年月日时分，生成唯一的时间码用于魔术计算
- **双击清零逻辑**：支持连续等号计数与两数相等判断等特殊逻辑

## 环境要求

- Python 3.7+（仅标准库 Tkinter，无需第三方依赖）

## 安装与运行

```bash
cd "python 计算机"
python main.py
```

## 核心逻辑

- `now_time`：由 `年月日时分` 拼接而成的时间码，如 `2026812345`
- `last_number = now_time - two_number_equal`：根据等号次数计算出「预计算数字」
- **魔术模式触发**：等号后点击任意数字，将立即显示计算出的完整数字而非输入内容

## 使用说明

1. 运行 `main.py` 启动计算器
2. 进行正常计算，输入表达式并按 `=` 得出结果
3. 等号后再点击任意数字，观察「魔术」效果——数字瞬间变为完整预计算数字
