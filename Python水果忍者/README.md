# Python水果忍者

基于 Pygame 的「水果忍者」切水果游戏。水果从屏幕下方抛出，玩家挥动鼠标切开水果得分，切中炸弹则游戏结束；切开的水果分裂为两半继续下落，汁液留在背景上逐渐消失。

## 功能特性

- **切水果玩法**：鼠标移动切割抛出的水果，获得分数
- **炸弹机制**：切中炸弹立即游戏结束（`游戏结束`）
- **水果分裂**：被切开的水果生成两半（`SlicedHalf`）继续受重力下落并旋转
- **果汁效果**：切割处留下果汁（`Juice`），逐渐透明消失
- **物理系统**：重力、初速度、抛射轨迹模拟水果抛掷效果
- **多种水果**：不同水果有不同模型与图像
- **中文字体支持**：自动寻找微软雅黑等字体渲染中文界面

## 环境要求

- Python 3.8+
- Pygame

```bash
pip install pygame
```

cd "Python水果忍者"

## 核心类设计

| 类 | 作用 |
|----|------|
| `Fruit` | 水果主体：抛射运动（重力、速度、旋转）与切割检测 |
| `SlicedHalf` | 切开的半块水果：继续下落、旋转并最终消失 |
| `Juice` | 果汁效果：停留在背景上，透明度递减直至消失 |
| `Game` | 游戏主控：主循环、碰撞检测、计分与状态管理 |

## 操作指南

1. 运行 `main.py` 启动游戏
2. 移动鼠标切割从屏幕下方抛出的水果
3. 避免切到炸弹，分数达到目标即为胜利

## 附：字体加载

程序会依次尝试以下路径加载中文字体，保证中文界面正常显示：

- 项目内 `msyh.ttc`
- 系统 `C:\Windows\Fonts\msyh.ttc`
- 兜底 `pygame.font.SysFont`
