# Python mc农场

基于 Pygame 的「我的世界」风格农场经营游戏。玩家扮演 Steve 在方块农田上种植多种作物（小麦、胡萝卜、土豆、甜菜、浆果、油菜、糯米、葡萄、辣椒等），作物随时间生长成熟，收获后可出售换取金币，并支持购买种子、洒水器、农夫等经营系统。

## 功能特性

- **多作物种植**：9 种作物，各有独立生长周期（受天气影响）、成熟阶段动画
- **天气系统**：天气影响植物生长速度
- **洒水器系统**：为土地提供生长速度加成
- **农夫系统**：自动照料农田，提升经营效率
- **交易系统**：收获作物出售换取金币，购买种子、工具与农夫
- **田地属性**：每块田地有独立的种植状态与附加属性
- **主菜单与设置**：完善的主菜单，包含游戏设置与存档导入
- **版本管理**：内置版本号显示与更新日志功能
- **存档系统**：支持保存与导入游戏进度

## 核心系统

### 作物系统

- `s_t`：各作物的成熟时间（帧数，60FPS 下约 13-17 秒成熟）
- `s_u`：作物成熟状态对应的贴图
- `Land_planting_situation`：每块田地的种植情况
- `growth_speed`：每块田地的生长速度加成

## 操作指南

1. 运行 `mc_farmer.py` 进入主菜单
2. 选择游戏设置（或直接开始新游戏/载入存档）
3. 使用鼠标选择种子，点击田地种植
4. 等待作物成熟（受天气与洒水器影响），点击收获
5. 前往交易系统出售作物、购买农夫与工具
