# Python 微信自动回复AI

基于 `wxauto` 的微信自动回复机器人，集成 DeepSeek 大模型实现智能对话，并通过 edge-tts 将回复合成为语音播放。程序监控指定联系人的新消息，自动调用 AI 生成回答并回复。

## 功能特性

- **微信接入**：通过 wxauto 控制已登录的微信客户端，自动获取与发送消息
- **AI 智能回复**：调用 DeepSeek API（OpenAI 兼容格式）生成自然语言回复
- **人设定制**：通过 `persona` 字典为不同联系人配置不同的 AI 人设
- **语音播报**：使用 edge-tts 将回复文本合成为中文语音并自动播放
- **消息去重**：通过消息唯一标识跟踪，避免重复处理同一条消息
- **聊天上下文**：结合历史聊天记录生成更贴切的回答
- **额度控制**：调用次数与时间上限控制，防止 API 额度超支
- **转人工**：用户发送「转人工」即停止自动回复

## 环境要求

- Python 3.8+
- 已登录的微信客户端（Windows）
- wxauto、openai、edge-tts、requests 库

```bash
pip install wxauto openai edge-tts requests
```

## 安装与运行

```bash
cd "Python 微信自动回复AI"
set DEEPSEEK_API_KEY=你的密钥
python main.py
```

## 核心逻辑

### 消息处理流程

```
获取消息 → 检查是否已处理 → 提取最新消息
    → 结合聊天记录调用 DeepSeek → 生成回答
    → edge-tts 合成语音并播放 → 微信发送文字回复
```

### 关键配置

| 项 | 说明 |
|----|------|
| `name` | 要回复的联系人名称 |
| `persona` | 不同联系人的 AI 人设提示词 |
| `loop_delay` | 消息轮询间隔（默认 2 秒） |
| 触发词「转人工」 | 停止自动回复，转为人工服务 |

## 操作指南

1. 登录 Windows 微信并保持打开
2. 设置 `DEEPSEEK_API_KEY` 环境变量
3. 运行 `main.py`，程序自动监听指定联系人的消息
4. 收到消息后自动 AI 回复，并播放语音合成结果

## 注意事项

- 微信版本升级可能导致 `wxauto` 接口失效，需要同步更新库
- 请遵守微信使用规范，避免高频操作导致账号异常
- API 调用有次数上限（默认 5 次），超出后自动转人工
