# Python人生重开模拟器

「人生重开模拟器」桌面版。随机投胎开启新的人生，从婴儿到老年经历各种随机事件，属性（颜值、智力、体力、家境、快乐等）在成长过程中受事件影响不断变化，最终解锁属于你的人生结局。提供 Tkinter 图形界面与 CMD 命令行两种玩法。

## 功能特性

- **随机人生模拟**：投胎随机分配初始属性，模拟完整人生
- **事件系统**：`events.json` 定义大量人生事件（升学、恋爱、意外、事业等），按年龄触发
- **年龄事件**：`age.json` 定义特定年龄阶段的事件序列
- **属性系统**：颜值、智力、体力、家境、快乐等属性随事件动态增减
- **结局判定**：根据人生轨迹达成不同的人生结局
- **双界面**：Tkinter 图形界面（深色主题）与 CMD 命令行界面
- **自动测试**：内置自动播放测试脚本验证游戏逻辑

## 环境要求

- Python 3.7+（仅标准库）

## 安装与运行

### 图形界面

```bash
cd "Python人生重开模拟器"
python tkinter_界面.py
```

### 命令行界面

```bash
python life_restart.py
```

或双击运行 `cmd命令运行.py`，自动在新 CMD 窗口启动命令行版。

## 核心实现

### 事件加载

- `get_all_events()`：读取 `events.json`，按事件 ID 建立字典
- `get_age_events()`：读取 `age.json`，过滤出 `events.json` 中存在的事件，按年龄建立映射

### 界面设计（tkinter_界面.py）

深色主题卡片式布局：

| 颜色 | 用途 |
|------|------|
| `#1a1a2e` | 深蓝黑背景 |
| `#16213e` | 卡片背景 |
| `#e94560` | 按钮背景 |
| `#a8d8ea` | 标签颜色 |

## 使用说明

1. 启动程序，随机投胎获得初始属性
2. 跟随年龄推进，面对各种人生事件做出选择（或自动判定）
3. 观察属性变化，经历完整一生
4. 人生结束后查看结局，可重新投胎再来一次
