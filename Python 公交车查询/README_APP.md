# 湘潭实时公交 · 最优乘车方案

**版本 v1.1.0** · 构建号 20261018 · 数据范围：湘潭市

输入两地，实时抓取公交车到站时间，动态规划最优乘车方案。
每一次查询都会重新拉取实时车辆数据，方案排序随之变化。

## 工作原理

### 数据来源

实时到站数据来自**车来了**平台（覆盖 488 个城市，湘潭 cityId=173）。
接口协议参考 MIT 开源项目 `Justintunsday/chelaile-api-server`。

高德开放平台 API **不提供公交车实时到站 ETA**，因此未纳入。

### 起点解析

1. 先按站点名搜索，命中同名公交站则直接使用
2. 未命中则取 POI 坐标，就近匹配周边站点（实测「未来素养」即走此路径）

### 耗时计算

```
总耗时 = 步行时间 + 等车时间 + 乘车时间 + 换乘等待
```

- 步行：Haversine 直线距离 × 1.35 路网系数 ÷ 4.5km/h
- 等车：**取实时车辆 ETA**（无车时按经验值 5 分钟）
- 乘车：优先用线路真实路径长度推算，无坐标时按站数估算

### 实时性

静态数据（线路站点表）走内存缓存；
**实时车辆 ETA 每次查询都重新拉取，永不缓存**。

实测同一站点连续采样，ETA 随车辆移动持续变化：

| 时刻 | 28路 | 67路 |
|---|---|---|
| 21:58:25 | 2 站 / 3.1 分 | 23 站 / 25.2 分 |
| 21:59:06 | 1 站 / 2.4 分 | 23 站 / 24.6 分 |
| 21:59:27 | 1 站 / 1.7 分 | 23 站 / 24.2 分 |

## 已知限制

- 仅支持湘潭市（`CITY_ID = "173"`），扩展需改城市常量
- 湘潭无地铁，故不含地铁换乘
- 部分中小城市线路无实时车辆数据，此时等待时间为估算值（界面会标注）
- 末班车收班后的线路仍会列出供参考，界面标注「已收班」
- 数据来自第三方平台，接口变动可能失效；仅供个人学习使用
