### Kivy GUI 踩坑（重要，下次直接照抄）
1. **中文渲染成方框**：Kivy 默认字体无 CJK，需 `LabelBase.register(name="CN", fn_regular=<系统字体>)`
   Windows 用 `C:/Windows/Fonts/msyh.ttc`（微软雅黑），Linux 用 NotoSansCJK / wqy-microhei
2. **字体注册必须放在 `App.build()` 里**，不能在模块导入期调用 ——
   模块期调用会过早初始化文本子系统，导致 `Window` 相关行为异常（表现为截图全黑）
3. **`Window` 可能为 None**（无图形会话时），`Window.clearcolor = BG` 会抛
   AttributeError → 必须 try/except 防护
4. **截图方式在此环境全部失效**：`Window.screenshot()` 返回全黑、
   `glReadPixels` 报异常、`ImageGrab` 抓不到（无图形会话）。
   → 改用**遍历控件树校验**：`isinstance(w, Label)` 检查 `.font_name` 与 `.texture.width>0`，
   这是本环境下唯一可靠的 GUI 验证手段
5. PlanCard 背景用 `canvas.before` 的 Rectangle + `bind(pos/size)` 同步；
   不要在 `_render` 里再 `canvas.before.clear()`，会把已画的背景清掉

### 重构过程中自己踩的坑
- 用 Edit 改 `_sync` 方法时，把后续 `head = BoxLayout(...)` 等语句吞进了方法体（缩进错乱）
- 批量 `sed` 替换 `Label(text=` → `Label(font_name=FONT, text=` 漏掉了多行形式的 Label
- 行号删除法（`sed -i '40d'`）删完必须立刻校验语法，避免重复函数定义
- 源码里中文是 `\uXXXX` 转义形式 → Edit 工具的精确字符串匹配会失败，需用 Python 脚本按行号改
