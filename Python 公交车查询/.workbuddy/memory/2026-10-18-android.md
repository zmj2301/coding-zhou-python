### 关键踩坑（全部已解决，务必记住）
1. **sdkmanager 需要 JDK 17**，本机默认 JDK 11 → 报 UnsupportedClassVersionError（class 61.0）
   解决：下载 Temurin/OpenJDK 17 解压到 E 盘，设 JAVA_HOME
2. **Gradle 无法下载**：`services.gradle.org` 307 重定向到 GitHub releases，该域名在本机不通
   → 改用手工打包链路，完全不依赖 Gradle（build_manual.sh）
3. **中文路径导致 Java 工具全废**：`E:\...\Python 公交车查询\...` 被 GBK 解码成乱码，
   apksigner 报 FileNotFoundException。已用对照实验确认：同一 APK 英文路径签名成功、中文路径失败。
   → 全部中间产物放 `E:\xtb-stage\`（纯英文）
4. **Git Bash 下 `rm -rf` 被安全包装器拦截**，导致后续 mkdir 行为异常
   → 改用 Python shutil.rmtree + shutil.copytree 完成暂存
5. **javac/d8 的 `@argfile` 里必须是 Windows 路径**（`E:\...`），
   混用 `/` 与 `\` 会报"无效的文件名"；换行符要用 `newline='\n'` 显式控制，
   否则 cat 拼接后换行丢失、所有路径粘成一行
6. **resources.arsc 必须不压缩**（ZIP_STORED），否则安装报
   `Failure [-124: ... requires the resources.arsc of installed APKs to be stored uncompressed
   and aligned on a 4-byte boundary]`。jar 的 `-0` 参数会被当输入项，
   → 用 Python zipfile 按文件名单独设置压缩方式
7. **LinearLayout 布局参数 0 不是 MATCH_PARENT**，是"宽度/高度为 0" → 界面全空白
   → 必须显式用 `MATCH_PARENT`(-1) / `WRAP_CONTENT`(-2)
8. **MuMu 模拟器 `input tap` 无效**（坐标点击不触发 onClick），
   → 用 intent extra 触发自动查询来做端到端验证
9. MuMu adb 端口 7555，启动约需 25 秒才监听；`adb pull` 的本地路径必须用 `\\` 且
   配合 `MSYS_NO_PATHCONV=1`，否则 Git Bash 会把 `/sdcard/x` 转成 Windows 路径
